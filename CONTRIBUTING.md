# Maintaining this GitHub profile

This repository contains the README shown on the [Waseem Aziz GitHub profile](https://github.com/waseem106).

## Updating featured projects

1. Choose publicly accessible repositories demonstrating a working feature, thoughtful implementation, or clear engineering learning.
2. Check that each link resolves and its README accurately describes what is implemented.
3. Prefer verified live demonstrations; label deployment targets clearly if availability is unverified.
4. Never list private client code or confidential projects without permission.
5. Keep the featured-projects section concise and remove stale links.

## Documentation checklist

- Explain the project's purpose in plain language.
- List technologies actually present in its source or dependencies.
- Provide correct local setup commands and prerequisites.
- Describe environment-variable names without publishing secret values.
- Add screenshots only if they represent real project behavior.
- Clearly distinguish completed features from ideas or future work.

## Change workflow

Create a descriptive branch, submit a pull request explaining the improvement, review links and Markdown, and merge into `main`. For substantial changes, verify the result on the rendered public profile.
